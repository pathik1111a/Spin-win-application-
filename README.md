# Spin N Win

Android Studio starter project for the Spin N Win rewards app.

## Current scope
- Kotlin + Android Gradle project
- Jetpack Compose UI
- Guest-mode demo experience
- Demo spin and scratch-card interactions
- Local demo coin balance only

## Important
This starter does **not** issue real UPI cash or Free Fire diamonds, run paid/real-money games, or grant rewards for ad views. The reward balance is illustrative and stored only in app memory. Before adding any real rewards, obtain and integrate an authorized reward-funding and fulfilment provider, add server-side validation and fraud controls, and review Google Play and ad-network policies.

## Open in Android Studio
1. Clone or download this repository.
2. Open the project root (the folder containing `settings.gradle.kts`).
3. Allow Gradle sync to complete.
4. Run the `app` configuration on an Android device or emulator.

## Build requirements
- Android Studio with a compatible Android Gradle Plugin
- JDK 17
- Android SDK 35
